# Agent Assignment Templates

Using these templates ensures that sub-agents receive only the critical information needed to succeed, preventing context exhaustion.

## 📋 Template: Implementation Task (Rust/TS)
**Goal:** [Explicit, measurable outcome]
**Context:**
- Repository: [Absolute Path]
- Target Schema: [Path to .json]
- Error Logs: [If applicable]
**Constraints:**
- No breaking changes to existing APIs.
- Follow [Project Standard, e.g., PEP8 / Rustfmt].
**Definition of Done:**
- Code is written to [Path].
- Unit tests pass.
- [Summary/Report] is provided.

## 📋 Template: Debugging / QA Task
**Goal:** Identify and document cause of [Error/Bug].
**Context:**
- Failed Command: [Command]
- Error Output: [Relevant logs]
- Expected Behavior: [Description]
**Definition of Done:**
- Root cause identified.
- Reproduction script provided OR fix implemented.
