# Continuous Learning Engine

## Overview
Intelligence is a function of the feedback loop between action and environmental response.

## The Pipeline
1. **Capture**: TZ Pro daemon captures raw data.
2. **Observe**: Spline Observer generates specialized traces.
3. **Label**: Anomalies and high-entropy events are flagged.
4. **Train**: Traces are fed into the Claw model fine-tuning pipeline.
